# Catatan rilis

## v1.1.1

- Tombol **KOSONGKAN INPUT** dipindah dari tab About ke bawah kolom input tab HPP.
- Versi: `1.1.1`, version code `3`.

## v1.1.0

- Input hitungan tersimpan otomatis di perangkat: nama produk, biaya, harga jual, potongan platform, jumlah produk, omset, dan target penjualan.
- Tombol **KOSONGKAN INPUT** di tab HPP untuk menghapus input tersimpan dan mengembalikan persentase modal ke 60.
- Riwayat dan satuan tidak berubah saat input dikosongkan.
- Versi: `1.1.0`, version code `2`.

## v1.0.0

Rilis pertama PRICHIEO.

- Kalkulator HPP dengan biaya bahan, tenaga kerja, overhead, kemasan, harga jual, potongan platform, dan jumlah produk.
- Satuan produk bisa diatur sendiri.
- Persentase modal otomatis dari hasil HPP dan harga jual, dengan nilai awal 60 persen.
- Pemisah Kas membagi omset menjadi uang modal dan laba kotor.
- Target Penjualan menghitung jumlah unit dari target omset dan harga jual.
- Riwayat tersimpan lokal, maksimal 50 entri, dengan empty state dan tombol hapus.
- Tab About berisi identitas aplikasi dan tautan Instagram `chiearrchie`.
- Ikon aplikasi berasal dari `PRICHIEO OK.svg` dengan sudut transparan.
- Package Android: `com.chiearrchie.prichieo`.
- Versi: `1.0.0`, version code `1`.
