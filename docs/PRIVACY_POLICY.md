# Kebijakan Privasi PRICHIEO

Berlaku sejak 23 November 2026.

PRICHIEO adalah aplikasi kalkulator bisnis untuk menghitung HPP, memisahkan uang modal dan laba, serta menentukan target penjualan. Aplikasi ini dibuat oleh Chiearrchie.

## Data yang disimpan aplikasi

Aplikasi menyimpan tiga jenis data di perangkat kamu:

- Riwayat hitungan HPP, pemisah kas, dan target penjualan, maksimal 50 entri terakhir.
- Satuan produk yang kamu atur, misalnya porsi, biji, box, atau unit.
- Persentase modal yang kamu pakai di Pemisah Kas.

Data tersebut disimpan secara lokal di perangkat dengan `SharedPreferences`. Data tidak dikirim ke server, tidak diunggah, dan tidak dibagikan kepada pihak lain.

## Izin aplikasi

Aplikasi ini tidak meminta izin kamera, lokasi, kontak, penyimpanan, atau izin sensitif lainnya. Build rilis Android tidak menyertakan izin `INTERNET`.

## Tautan eksternal

Tab About berisi tautan ke Instagram `https://www.instagram.com/chiearrchie`. Tautan ini membuka browser atau aplikasi Instagram di luar PRICHIEO. Setelah tautan dibuka, kebijakan privasi Instagram yang berlaku.

PRICHIEO tidak memakai iklan, pelacak, analitik, atau layanan pihak ketiga lainnya di dalam aplikasi.

## Menghapus data

Kamu bisa menghapus seluruh riwayat lewat tombol **HAPUS RIWAYAT** di tab Riwayat. Satuan produk dan persentase modal akan kembali ke nilai awal saat aplikasi dihapus dari perangkat.

## Retensi

Riwayat tetap tersimpan di perangkat sampai kamu menghapusnya sendiri atau menghapus aplikasi. Kami tidak menyimpan salinan data tersebut.

## Anak-anak

Aplikasi ini tidak ditujukan untuk anak di bawah 13 tahun.

## Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan disertakan bersama rilis aplikasi dan tanggal berlakunya diperbarui.
