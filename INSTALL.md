# Cara memasang PRICHIEO di Android

## Cara paling mudah: dari tab Releases

1. Buka repository GitHub ini di browser.
2. Klik tab **Releases** di sebelah kanan atas daftar file.
3. Klik rilis terbaru, misalnya **PRICHIEO v1.0.0**.
4. Di bagian **Assets**, klik `prichieo-v1.0.0-release.apk`.
5. Tunggu proses unduh selesai.
6. Buka file APK tersebut dari panel unduhan.
7. Android akan meminta izin memasang aplikasi dari sumber tidak dikenal. Pilih **Izinkan** atau **Allow**.
8. Klik **Install**, lalu **Open** setelah selesai.

Kalau memakai BlueStacks, tarik file APK ke jendela BlueStacks atau klik **Install apk** lalu pilih file tersebut.

## Kalau muncul peringatan

- **Aplikasi tidak terpasang**: kemungkinan versi lama masih terpasang. Uninstall dulu PRICHIEO lama, lalu ulangi dari awal.
- **Install blocked**: buka **Settings > Security > Install unknown apps**, lalu aktifkan izin untuk browser atau file manager yang kamu pakai.
- **App not installed** karena konflik tanda tangan: uninstall versi lama dulu. APK baru dan lama memakai kunci yang sama, jadi seharusnya tidak terjadi kalau APK berasal dari repository ini.

## Persyaratan

- Android 7.0 atau lebih baru.
- Ruang penyimpanan sekitar 50 MB.

## Tentang keamanan

APK di rilis ini ditandatangani dengan kunci resmi PRICHIEO. Kunci tersebut tidak disimpan di repository publik. Jangan mengganti atau menandatangani ulang APK jika kamu tidak tahu apa yang dilakukan, karena pembaruan berikutnya bisa gagal terpasang.
